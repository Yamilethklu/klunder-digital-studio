# Klunder Digital Studio

Sitio profesional, catálogo de proyectos, formulario de cotización y panel privado de ingresos.

Stack: Next.js 15, React 19, Supabase.

## Configuración

1. `npm install`
2. Copia `.env.example` a `.env.local` y agrega las variables públicas de Supabase.
3. Ejecuta `supabase.sql` desde el editor SQL de tu proyecto Supabase.
4. Crea tu usuario en Supabase Authentication y autorízalo en la tabla `admins`.
5. `npm run dev`

En Vercel agrega las mismas dos variables. Las imágenes del portafolio son ilustrativas. No se incluyen credenciales privadas.
